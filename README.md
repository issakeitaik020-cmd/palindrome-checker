# Palindrome Checker

A utility for checking whether text reads the same in reverse.

## Features

- Text normalization
- Palindrome detection
- Instant results

## How to Use

Enter a word or sentence and click Check Palindrome.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
